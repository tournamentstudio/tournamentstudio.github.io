# Activity artwork

I wanted the game to remain recognizable when an organizer changes its theme.
TournaStudio has a separate set of fourteen activity icons for creation, library
covers, workspace identity and presentation. Themes still control materials,
colors and decorative patterns. The SVG paths are original project artwork,
bundled locally under the repository's MIT license.

## Gol Ya Pooch

The [Persian description on Visit Iran](https://visitiran.ir/fa/attraction/%DA%AF%D9%8F%D9%84-%DB%8C%D8%A7-%D9%BE%D9%88%DA%86)
describes hiding a small object in a closed fist. I used that physical gesture
for the emblem: two closed fists with a bead between them. Both teams receive
the same artwork. The bead's position is decorative and never follows the
referee's concealed-position field.

Persian game-set photographs, including the
[modern set shown by Cafe Toyz](https://cafetoyz.com/product/%DA%AF%D9%84-%DB%8C%D8%A7-%D9%BE%D9%88%DA%86-%D9%85%D8%AF%D8%B1%D9%86/),
informed the separate bead, tabletop bell and card symbols. These represent
configurable play controls, not a claim that every traditional variant uses
the same equipment or rules. Persian arches and geometric frames remain part
of the themed backgrounds.

No reference photograph, television-show logo, portrait or commercial card art
is included in the application. The icons have no network dependency and accept
no match state or private data.

## Other games

The icons use recognizable equipment: football and futsal have different ball
and court compositions; tennis, table tennis and badminton have their own
racquet, paddle and shuttle shapes. Basketball and volleyball use different
seam patterns. Chess, esports, racing, board games and quiz competitions use a
knight, gamepad, checkered flag, dice and pawn, and question book respectively.
The generic competition uses a trophy.

Icons next to text are decorative for screen readers. An explicit label makes
a standalone icon an image with an accessible name. Unknown sport identifiers
fall back to the generic icon without rendering imported markup.

## Exported scenes

Scoreboard emblems and champion-poster scenes extend those original shapes.
Each activity has related geometry: a court, table, circuit, board or book.
Gol Ya Pooch places the closed hands above a table with a bell and cards inside
an arch. The export renderer receives public tournament data only. Scene
geometry is static and cannot respond to a concealed position or private log.
