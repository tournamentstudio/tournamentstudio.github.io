# Getting help with TournaStudio

Start with the [user guide](USER_GUIDE.md) for creating a tournament, entering results, sharing copies, and restoring backups. The [feature matrix](FEATURES.md) records which rules and workflows are supported. For setup or deployment, use the [README](README.md).

## Protect your copy first

Before troubleshooting a saved tournament, export a `.tourney` backup if the app still opens. Keep the original file when testing an import or update. Do not clear site data as a first step: it can remove tournaments and revision history.

Check that you are using the same browser profile and site address where the tournament was saved. A second device, private window, local preview, or different browser has separate storage. Sharing transfers a copy; it does not create a live connection between devices.

A protected backup needs its correct secret. There is no recovery service that can unlock it or retrieve a tournament from a cleared browser.

## Ask with a small example

[Ask a question in Discussions](https://github.com/tournamentstudio/tournamentstudio.github.io/discussions) for help with a workflow or competition setup. Include the format, entrant count, and a few fictional results when rules are involved.

For a defect, [open an issue](https://github.com/tournamentstudio/tournamentstudio.github.io/issues/new/choose) with the screen or workflow, browser version, steps, and exact error text. Explain what you expected. Use the competition-rule form to propose a new pairing, scoring, or qualification policy.

Screenshots and small sample files can help, but GitHub issues and discussions are public. Remove names, notes, coordinates, and other private information before posting. Reproduce the problem in a new fictional tournament when possible. Do not post a private share code or encrypted backup with its secret.

For a suspected vulnerability, use [private security reporting](SECURITY.md). For a contribution, see [CONTRIBUTING.md](CONTRIBUTING.md). Help is provided through the project, with no guaranteed response time.
