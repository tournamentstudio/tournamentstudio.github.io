# TournaStudio brand assets

The mark continues the bracket symbol used in the app icon. It combines a forest green field with a lime bracket and two round endpoints.

## Files

- `logo-mark.svg`: editable vector mark, 1024 by 1024.
- `logo-avatar.png`: organization avatar, 1024 by 1024. The mark fits inside a circular crop and remains readable at 32 pixels.
- `wordmark.svg`: mark and TournaStudio name on a transparent background.
- `social-card.svg`: vector source for the repository preview, 1280 by 640.
- `social-card.png`: ready to upload as the GitHub social preview, 1280 by 640.

Use the avatar for square or circular profile pictures. Use the wordmark on a light background. Keep clear space around the mark and preserve its proportions.

## Colors and lettering

| Role | Color |
| --- | --- |
| Forest | `#173b32` |
| Lime | `#dafa91` |
| Cream | `#f6f5ec` |
| Muted green | `#c4d4c3` |

The lettering is outlined from the locally bundled Inter font. The SVG files have no remote fonts, linked images, scripts, or other external resources. Inter is covered by the SIL Open Font License in [the local license copy](../licenses/inter.txt). The original bracket artwork and exported assets follow the repository's MIT license.

PNG files were rendered from their SVG sources with local Chromium through Playwright at the exact output dimensions. The avatar uses a solid forest background so GitHub can crop it without transparent corners. The SVG title and description retain the visible wording for assistive tools.
